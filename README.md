### 🌱 About Me

I am an IT student and aspiring **Full-Stack Cloud Developer** who enjoys turning ideas and requirements into complete, useful applications.

My current focus is full-stack web development, particularly backend systems built with **Node.js, Express, MongoDB, C#, and ASP.NET Core**. As I strengthen my programming skills, I am also studying networking, cybersecurity, and Microsoft Azure so I can build applications that are secure, reliable, and ready for the cloud.

I value teamwork, clear communication, continuous learning, and software that solves real problems.

---

### 🧭 My Development Path

```text
College and Capstone
        ↓
Strong Full-Stack Foundations
        ↓
Secure Backend Development
        ↓
Azure Deployment and Cloud Networking
        ↓
Full-Stack Cloud Developer
        ↓
Cloud Security / DevSecOps / Application Security
```

#### 1. Current Stage — Build and Finish

- Complete and improve my capstone project.
- Strengthen JavaScript, Node.js, Express, MongoDB, C#, and ASP.NET Core.
- Practice frontend development, API design, databases, Git, debugging, and testing.
- Turn completed projects into clear portfolio case studies.

#### 2. Next Stage — Build Secure Systems

- Apply authentication, authorization, user roles, validation, and secure password storage.
- Study common web vulnerabilities and the OWASP Top 10.
- Improve logging, error handling, dependency security, and secrets management.
- Use cybersecurity labs only in systems I own or am authorized to test.

#### 3. Cloud Stage — Deploy and Operate

- Learn Microsoft Azure Fundamentals.
- Deploy a complete web application to Azure.
- Use cloud databases, storage, identity, secrets, monitoring, and backups.
- Connect networking knowledge to DNS, HTTPS, ports, firewalls, subnets, and cloud virtual networks.

#### 4. Professional Stage — Specialize Through Experience

- Begin in a Junior Full-Stack, Backend, Associate Software Engineer, or Cloud Developer role.
- Grow into a **Full-Stack Cloud Developer**.
- Develop deeper expertise in **application security, DevSecOps, or cloud security** based on real professional experience.
